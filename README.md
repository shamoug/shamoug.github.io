# shamoug.github.io

The root of the site. It holds `.well-known/assetlinks.json`, which lets the Mandata app for Android open the pairing
links of Mandata's QR code (`https://shamoug.github.io/mandata/open.html#...`) without the browser. The fingerprint is
that of the key that signs the app (see the [mandata](https://github.com/shamoug/mandata) repository). Everything
else goes to [Mandata](https://shamoug.github.io/mandata/).
