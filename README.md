# shamoug.github.io

The personal portfolio of Aladdin Shamoug, served at the root of the site. It also holds
`.well-known/assetlinks.json`, which lets the Mandata app for Android open the pairing links of
Mandata's QR code (`https://shamoug.github.io/mandata/open.html#...`) without the browser. The
fingerprint is that of the key that signs the app (see the [mandata](https://github.com/shamoug/mandata)
repository). Mandata itself lives at [shamoug.github.io/mandata](https://shamoug.github.io/mandata/).
